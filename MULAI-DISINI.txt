PAKET TIM PKM - SMP NURUL HUDA
7 November 2026

JALANKAN DENGAN DOCKER

1. Install Git dan Docker Desktop, lalu buka Docker Desktop.
   Windows: aktifkan WSL 2 dan gunakan Linux containers.
2. Clone repository atau buka folder project yang sudah tersedia.
   Simpan di luar OneDrive.
3. Salin backend/.env.example menjadi backend/.env jika belum ada.
   Isi POSTGRES_PASSWORD. Jangan mengganti password volume database lama.
4. Jalankan dari root project:

   docker compose --env-file backend/.env -f compose.dev.yaml up --build -d --wait

5. Buka http://localhost:3000 atau http://localhost:3000/admin.
   PostgreSQL, migration 23 tabel, backend, dan frontend berjalan bersama.
6. Buat akun admin sekali dengan perintah interaktif:

   docker compose --env-file backend/.env -f compose.dev.yaml run --rm backend npm run admin:create --workspace=@nurul-huda/backend

JALANKAN LAGI

   docker compose --env-file backend/.env -f compose.dev.yaml up -d --wait

BERHENTI

   docker compose --env-file backend/.env -f compose.dev.yaml stop

SETELAH PULL PERUBAHAN

   docker compose --env-file backend/.env -f compose.dev.yaml up --build -d --force-recreate --wait

ATURAN TIM

- Gunakan Docker untuk menjalankan project; tidak perlu npm ci di host.
- Kerjakan pada branch sendiri, periksa hasil, lalu push dan buat pull request.
- Jangan kirim .env, password, node_modules, atau data pribadi ke GitHub.
- Jangan gunakan down -v karena menghapus volume database.
- Database setiap anggota terpisah. Git membawa schema, bukan isi database.
- Backend seluruh menu belum selesai. Tersedianya tabel bukan berarti
  seluruh fitur sudah terhubung ke database.
